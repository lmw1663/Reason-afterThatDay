> 방법: ① 현재 앱 코드 감사 ② 사용자 레퍼런스(`docs/design/` Mobbin 큐레이션) 해독 ③ 2025–2026 모바일 UX/UI 트렌드 리서치 — 세 갈래를 종합

## 0. 한 줄 결론

2026 메타 트렌드는 **"비주얼 곡예의 종말 → Calm UI(차분한 인터페이스)"** 이고, 사용자가 모은 레퍼런스도 전부 **"무채색 위에 핵심 정보 하나만 영웅처럼 키우는 절제된 데이터 미니멀리즘"** 이다. 즉 할 일은 *화려하게*가 아니라 **① 깨진 토대를 조이고 ② 레퍼런스식 절제된 고급감으로 끌어올리기**.

## 1. 현재 앱 감사 (코드 근거)

### 강점 (이미 좋아진 것 — 유지)
- **IA/플로우 안전성**: 4탭→3탭+동적 매듭탭, 홈 단일 CTA, 페르소나·D+N·안전잠금 게이트.
- **모션 토큰화**: `constants/motion.ts` spring 4종을 ScreenWrapper·TabBar가 공유.
- **접근성 실재**: a11y prop이 59개 파일/212회. MoodSlider는 adjustable + increment/decrement.
- **위기 안전 인프라**: 핫라인 JSON·C-SSRS 게이트·페르소나 매핑 → 2026 멘탈헬스 "table stakes"를 이미 초과.

### 약점 (고칠 것 — 근거 파일:라인)
| 코드 | 문제 |
|------|------|
| `tailwind.config.js:18` (extend) + `constants/colors.ts:18` | **gray ramp가 50/400/600/800뿐.** `text-gray-500`(100회)·`-300`(47)·`-200`(16)·`-100`(3)·`-700`(3)이 커스텀 토큰에 없어 Tailwind 기본 **쿨그레이로 폴백** → 앱의 따뜻한 taupe 그레이와 두 계열이 섞임. (extend 병합이라 "무색"이 아니라 "off-palette 폴백"이 정확한 진단.) **앱에서 가장 많이 쓰는 텍스트색이 디자인 토큰에서 안 옴.** |
| 동일 | purple-300/500/700(4회)·amber-700(2회)도 동일 폴백 |
| 화면 전역 | 다크 서피스 단차가 토큰화 안 됨 — `rgba(...,0.18/0.22)` 즉석 보더, shadow 하드코딩 |
| 전역 | spacing/radius/elevation 토큰 부재 → radius 16/20/24 혼용 |
| 일기 흐름 (`journal/emotion.tsx`, `physical.tsx`, `index.tsx`) | **ProgressDots가 거짓** — 5화면을 4 dots로, 1~3화면이 같은 점 + "1/4"와 "1/3" 이중 번호 |
| `EmotionalCheckModal.tsx` | 저강도 위기 모달(`consecutive_low`/`late_night`)이 **범용 Modal과 외형 동일** → 안전 둔감화 |
| 전역 | 색 7패밀리 의미 인플레이션 (amber=좋음/경고/정보) + teal/amber 400 다크배경 WCAG 대비 미달 |
| 9곳 | 이모지 잔존 (🫁🌱🍂📅💜⚫ 등 — 위기/유예/졸업 리포트) |
| `records.tsx`/`me.tsx` | `Card` 컴포넌트 두고 인라인 surface 카드 재작성 |
| 38곳 | BackHeader가 ScrollView 첫 자식 → 스크롤 시 사라짐 |

## 2. 레퍼런스 해독 (`docs/design/` — Mobbin 큐레이션 22장)

사용자가 지향하는 디자인 언어 = **무채색·저채도 표면 + 거대 핵심 숫자 + 작은 회색 보조라인 + 큰 radius 카드 + pill 컨트롤 + drag-handle 블러 시트**. 화려함이 아니라 위계·여백으로 고급감.

| 앱 | 가져올 것 | Reason 적용 |
|----|----------|-------------|
| **Anz+** | 거대 중앙 숫자 + 작은 라벨, 카드 분리, 우측정렬 아이콘 메뉴 | **D+N = 영웅 숫자** |
| **Apple Stocks** | 인라인 sparkline 한 줄(라벨·추세·현재값), 다크 위 컬러는 데이터에만 | **감정온도 추이 sparkline** (단 적/녹 신호등 금지) |
| **Apple Pay/Wallet** | 카드 스택 적층(누적 은유), 미니멀 Done | **매듭 = 카드 스택** (= "끝이 아닌 챕터" 규칙과 1:1) |
| **Fi** (펫 GPS 트래커, *핀테크 아님*) | 수평 스텝 인디케이터, 동위 2열 카드, 비난 없는 빈상태 | **유예 진행 = 스텝 인디케이터**, 따뜻한 빈상태 |
| **Disney+** | 다크+흰 pill CTA, 시네마틱 무드 | 위기/매듭 진입 등 무게감 화면 한정 |

> 주의: `PATTERNS.md`의 제안 컬러는 **라이트테마** 기준인데 앱은 다크 → 구조만 차용, 컬러는 다크로 재매핑. (`trendy-ui-revamp-plan.md`에 이미 결정된 방향 있음 — 정합 확인.)

## 3. 2025–2026 트렌드 (적합도 평가)

| 트렌드 | Reason 적합도 | 적용 |
|--------|---------------|------|
| **Calm UI / 비주얼 곡예의 종말** | ★ 최우선 | 북극성. 1화면 1결정, 결정 피로 최소화 |
| 다크를 1차 캔버스로 (그림자 대신 톤 단차) | 적합 | **4단계 서피스 토큰** |
| 표현적 대형 숫자 (저채도) | 적합 | D+N·통계 |
| 부드러운 게이미피케이션 (처벌 없는 누적) | 적합 | 매듭/유예 진행 (= "재발/실패 어휘 금지"와 일치) |
| 햅틱 + 콤파운드 제스처 (탭 폴백 필수) | 부분 | **무드패드 햅틱 + 탭 폴백** |
| 2D 무드 입력 = Russell's Circumplex/Affect Grid | 적합 | 방금 만든 패드가 학술적으로 정합 → 햅틱·점진공개 보강 |
| Bento grid | 부분 | 통계 대시보드 한정 (질문 화면 금지) |
| Liquid Glass / 글래스모피즘 | 부분 | 임시 레이어(시트)만, 본문·위기 화면 금지 |
| AI 스트리밍 "타이핑 효과" | 부적합 | 채팅 UI 금지 규칙과 충돌 → 정적 표시 |

## 4. 실행 계획 (우선순위 Tier)

### Tier 0 — 토대 🔴 (안 보이지만 전역, 최고 ROI)
- [x] **0-1 gray ramp 100~900 + 누락 accent(purple 300/500/700, amber 700) 토큰 정의** (`colors.ts`/`colors.js` 동기화)
- [x] 0-2 4단계 다크 서피스 토큰 (배경/카드/상승/오버레이) — surfaceElevated/surfaceOverlay + 보더 틴트·스크림 토큰, 즉석 rgba 11곳 치환, Modal L2 승격
- [x] 0-3 spacing/radius/elevation 토큰 표준화 — `constants/layout.ts` 신설, radius 리터럴 20곳·shadow 4곳 토큰화 (spacing은 신규 인라인 스타일용 선언)

### Tier 1 — UX 정확성 🟠 (신뢰·안전)
- [x] 1-1 일기 흐름 ProgressDots/번호 정합화 (나침반 수준 단일 체계)
- [x] 1-2 위기 모달 전용 시각 variant (coral 헤더 아이콘·솔리드·햅틱, 본문 반말 유지) — Modal `variant="crisis"` + expo-haptics Warning + 전화 아이콘 bell→phone 정정

### Tier 2 — 레퍼런스식 고급감 🟢
- [x] 2-1 D+N 영웅 숫자 강화 (Anz+) — "D+" 접두 28px 회색(통화기호 패턴) + 숫자 64px tabular-nums + 이별날짜 보조라인 + a11y 단일 낭독
- [x] 2-2 감정온도 인라인 sparkline (Stocks, 저채도·신호등 금지) — `Sparkline` 컴포넌트 + 홈 일기 카드 통합, upsertEntry 낙관적 중복 버그 동시 수정
- [ ] 2-3 무드패드 업그레이드: 햅틱 + 탭 폴백 + 감정단어 점진공개
- [ ] 2-4 매듭 카드 스택 적층 (Apple Pay Wallet)
- [ ] 2-5 유예 수평 스텝 인디케이터 (Fi)
- [ ] 2-6 빈상태·완료 화법(따뜻+미니멀)

### Tier 3 — 마감 일관성 🔵
- [ ] 3-1 이모지 9곳 → Icon
- [ ] 3-2 색 7패밀리 역할 정리 + teal/amber WCAG 보정
- [ ] 3-3 인라인 카드 → `Card` pressable variant
- [ ] 3-4 BackHeader 상단 고정 (ScrollView 밖)
